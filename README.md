# Такси XXI — Маршрут здоровья

MVP браузерной мини-игры для проекта Медицинского центра «XXI век».

## Что уже работает

- 3 полосы движения;
- управление стрелками / A-D / свайпами;
- жетоны XXI;
- бонусы: жизнь, щит, ускорение;
- препятствия: конусы и лужи;
- счёт, жизни и ежедневная миссия;
- адаптация под мобильный экран.

## Запуск

Откройте `index.html` в браузере.

Для локального сервера можно использовать, например:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Структура

- `index.html` — интерфейс;
- `styles.css` — стили;
- `game.js` — игровая логика;
- `assets/logo.png` — логотип клиники.

## Дальнейшее развитие

Петербургские маршруты, нарисованный спрайт реального медицинского такси, сезонные миссии, награды и интеграция с приложением клиники.
