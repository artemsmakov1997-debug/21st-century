# Такси XXI — Маршрут здоровья

Браузерный прототип мини-игры для Медицинского центра «XXI век».

## Текущая версия

- атмосферная локация: вечерняя петербургская набережная;
- top-view медицинское такси в фирменных цветах;
- счёт, жизни, жетоны и ежедневная миссия;
- бонусы: жизнь, щит, ускорение;
- препятствия: конусы и лужи;
- управление свайпами и клавишами;
- адаптация под мобильный экран;
- автоматическая публикация через GitHub Pages.

## Запуск

Откройте `index.html` либо запустите локальный сервер:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000/`.
